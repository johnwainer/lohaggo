Opción 1: Herramientas Online (Recomendado)

La forma más fácil de generar todos los iconos necesarios es usar herramientas online especializadas:

🚀 PWA Builder 🎯 Favicon Generator ⚡ Favicon.io
1
Descarga el icono SVG

Haz clic derecho en la imagen de arriba y guarda el archivo icon.svg

2
Sube a la herramienta

Abre cualquiera de las herramientas de arriba y sube el archivo icon.svg

3
Descarga los iconos

Descarga el paquete de iconos generados

4
Coloca en /public

Extrae y coloca todos los archivos PNG en la carpeta public/ del proyecto

Opción 2: Usando Sharp (Node.js)

Si prefieres generar los iconos localmente con código:

$ npm install --save-dev sharp
$ npm run generate-icons

Nota: Necesitas tener Node.js instalado y el paquete sharp puede requerir dependencias del sistema.

Verificar Configuración

Una vez que hayas generado y colocado todos los iconos, verifica que todo esté correcto:

$ npm run check-pwa

Este comando verificará que todos los archivos necesarios estén en su lugar y que la configuración sea correcta.
