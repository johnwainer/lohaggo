## ⚡ Acción Inmediata (2 minutos)

### 1. Generar Iconos PNG

**Opción más rápida:**
1. Abre en tu navegador: http://localhost:3000/generate-icons.html
2. Ve a: https://www.pwabuilder.com/imageGenerator
3. Sube el archivo `public/icon.svg`
4. Descarga el ZIP con todos los iconos
5. Extrae y copia los archivos PNG a la carpeta `public/`

### 2. Verificar

```bash
npm run check-pwa
```

### 3. Probar

```bash
npm run dev
```

Abre http://localhost:3000 y verás el prompt de instalación después de 3 segundos.

## 📱 Instalar en tu dispositivo

### Android
1. Abre la app en Chrome
2. Menú (⋮) → "Instalar app"

### iOS
1. Abre la app en Safari
2. Compartir → "Agregar a pantalla de inicio"

### Desktop
1. Busca el ícono de instalación en la barra de direcciones
2. Click en "Instalar"
